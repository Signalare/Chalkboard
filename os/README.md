# os

Buildroot external tree (`BR2_EXTERNAL`) producing the universal aarch64
Chalkboard image (SPEC §5). Buildroot itself is downloaded at a pinned version
rather than vendored. The tree arrives with
[#5](https://github.com/Signalare/Chalkboard/issues/5), after the boot-slot
spike in [#3](https://github.com/Signalare/Chalkboard/issues/3).
